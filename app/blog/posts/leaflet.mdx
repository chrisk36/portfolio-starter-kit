# Leaflet

Leaflet is a social mobile app for outdoor exploration built during **HackMIT 2025**. Users discover trails and parks sourced from the National Park Service, follow friends' adventures, rank locations, and compete on a leaderboard for most active explorer.

My role was design and frontend interactivity. The team handled backend infrastructure and API integration; I was responsible for the app's visual identity and making the experience feel polished and alive.

## What I Built

I owned the full visual layer of the app:

- **Visual identity** — defined the color palette, typography, and overall aesthetic tone across all screens
- **Map interface** — designed and implemented custom map pins, color logic, and interaction patterns using the Google Maps API to make location discovery feel native to the app rather than generic
- **Animations** — built a custom loading sequence and added micro-animations and transitions throughout to smooth navigation and reinforce user actions
- **Core screen design** — shaped the layout and interaction patterns for the key exploration, social, and ranking flows

## How We Built It

- **Frontend:** Expo Go, React Native
- **Backend:** Firebase (Firestore + Authentication)
- **APIs:** National Park Service API, Google Maps API
- **Design:** Figma
