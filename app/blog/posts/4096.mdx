# 4096

4096 is a tile-based puzzle game implemented as my final project for **CIS 1200** and my first fully independent coding project.

The game follows the classic 2048-style mechanics, where players slide numbered tiles across a grid to combine matching values. The objective is to continue merging tiles until reaching the 4096 tile.

## What I Built

- A complete **game loop** handling user input, tile movement, and win/loss conditions  
- Logic for **tile merging**, score tracking, and randomized tile generation  
- Grid-based state management to ensure valid moves and consistent gameplay behavior  

## What I Learned

This project was my introduction to structuring a non-trivial program from scratch. It helped me develop foundational skills in:

- Breaking a larger problem into manageable components  
- Debugging game logic and edge cases  
- Translating game rules into clear, maintainable code  

Although simple in scope, this project marked the start of my interest in building interactive systems and games.
