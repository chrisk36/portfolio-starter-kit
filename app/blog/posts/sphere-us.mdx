# SphereUs — Influencer Overlap Analysis

SphereUs is an influencer research and analytics platform that helps brands and agencies understand how creator audiences overlap — so they can balance incremental reach against conversion-driving frequency in multi-touch campaigns.

**Program:** Penn SPARK × SphereUs · Fall 2025 Client Project  
**My role:** Full-Stack Developer & UX contributor

## The Problem

Influencer campaigns rarely work as single-touch funnels, but brands don't have clear tools to tell whether multiple creators are reaching new audiences or repeatedly hitting the same people. Teams can usually identify which creators are popular — but not whether a given set will be redundant. That uncertainty turns campaign planning into guesswork.

## What I Contributed

I built the overlap analysis feature end-to-end and contributed to the dashboard's UX structure. The design goal was making overlap data *instantly actionable* — not just showing a percentage, but surfacing the context and next steps a marketer actually needs.

Key decisions I made:
- Structure the dashboard to lead with the most important metric (overall overlap %) before showing breakdowns by creator
- Generate contextual recommendations alongside the overlap score, not separately
- Scope the campaign goals input to drive the right metrics and creator types from the start of the flow

## 1. Campaign Goals Screen

Before seeing any overlap data, users define their campaign objective — reach vs. conversion vs. awareness. This single input changes which metrics the dashboard emphasizes and which creator types the system recommends, reducing confusion and keeping teams aligned on what success looks like.

## 2. Analysis Dashboard

The dashboard is structured to speed up decisions: overview first (overall overlap %, total/unique/shared followers), then individual creator breakdowns (quick add/remove for testing combinations), then actionable insights.
