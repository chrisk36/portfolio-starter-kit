# Submarine Swim Scene

Submarine Swim Scene is a stylized underwater animation built around **big,
geometric, readable shapes** and a calm-but-alive sense of motion. The scene is
a looping study where the submarine and surrounding fish drift **up/down and
left/right** in repeating cycles.

To keep the loop from feeling mechanical, I offset each animated element with
different start times so the motion doesn’t “reset” all at once. The result is a
more natural rhythm — like a real underwater environment where everything moves
independently, but still feels cohesive.

## Animation Notes

- **Looped motion:** each object follows a smooth cyclic path (vertical bob + horizontal drift)
- **Offset timing:** different start times prevent the scene from moving in sync
- **Natural feel:** subtle variation across objects keeps the loop believable
- **Silhouette-first:** forms stay readable from a distance and in motion

## Design Focus

- Big, simple geometry that reads instantly
- Clear color blocking and shape separation
- Motion that feels calm and buoyant rather than rigid


## Tools

- 3D scene layout and modeling
