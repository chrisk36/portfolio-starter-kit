# Roomies

Roomies is a cross-platform mobile app that makes coordinating life with roommates more structured — and more engaging — by turning shared household tasks into a lightweight competitive system.

Built through **Penn SPARK** with an 8-person cross-functional team. My role was **Frontend Developer**, focused on gamification design and several core user flows.

## Impact

During pre-launch testing, the app drove a **30% increase in daily task completion** across **50+ beta users**. That result came directly from two systems I built: a push notification layer that surfaced tasks at the right moment, and a points-based reward model that made completing chores feel worth doing.

## What I Built

I architected the task assignment workflow, a personalized dashboard, and the gamified leaderboard using React Native and Tailwind CSS. The leaderboard ranks roommates within a group by points — rewarding consistency and participation, not perfection.

I also led design on five core screens: Tasks, Calendar, Leaderboard, Profile, and the Avatar customization page, plus the landing, login, and sign-up flows. Motion details and animated transitions were added throughout to make navigation feel polished and responsive.

## Gamification System

The points system is intentionally low-stakes: completing any assigned task earns points, which feed a group leaderboard. The design goal was friendly competition that reinforces accountability — not a system that punishes people for missing a day. Avatar customization gives each user a persistent identity within the group, which strengthened engagement during testing.

## Tech Stack

- **Frontend:** React Native, Tailwind CSS
- **Backend:** Firebase (Firestore + Authentication)
- **Design:** Figma
- **Infra:** Push notification system for task reminders
